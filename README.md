# 🏥 MEDICAL STORE MANAGEMENT

A Modern Medical Store Management System built with **Vite + React + TypeScript + Tailwind CSS (shadcn/ui)**. This dashboard is designed to simplify pharmacy management — from medicine inventory, customer handling, billing, and sales reports.

---

## ✨ Features

- 📦 Add & manage medical products
- 🧾 Generate and manage bills
- 👥 Customer and supplier database
- 📊 Real-time dashboard with stock status and sales stats
- 🌐 Fully responsive interface using TailwindCSS + shadcn/ui

---

## 🛠️ Tech Stack

- ⚡ Vite
- ⚛️ React
- 🧑‍💻 TypeScript
- 🎨 Tailwind CSS
- 🧩 shadcn/ui components

---

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/kbansal17/pharma-point-dashboard.git
cd pharma-point-dashboard

# 2. Install dependencies
bun install   # or npm install

# 3. Start the dev server
bun run dev   # or npm run dev
